# Security

If you believe you have found a **security vulnerability** in EasyGamepad,
please report it **privately** to the maintainer (repository owner) instead of
opening a public issue with exploit details.

Include:

- A short description of the impact
- Steps to reproduce (if safe to share)
- Affected version / commit when known

This project does not run a formal bug bounty program. Reports are handled
in good faith for responsible disclosure.

General bug reports and feature requests can use
[GitHub Issues](https://github.com/edgardmessias/easygamepad/issues) on the project
repository.
